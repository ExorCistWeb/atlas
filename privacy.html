Политика обработки персональных данных

До публикации укажите полное наименование оператора, ИНН, ОГРН, юридический и почтовый адрес. Текст должен быть проверен юристом с учётом фактических сервисов аналитики, рассылок и платежей.

1. Общие положения

Настоящая политика описывает принципы обработки данных пользователей платформы «Стэди». Оператор обрабатывает только те сведения, которые необходимы для регистрации, построения учебного маршрута, предоставления поддержки и исполнения обязательств по подписке.

2. Какие данные используются

Имя, контактные данные, класс и учебные цели, ответы на задания, история занятий, технические сведения о сессии и информация о платежном статусе. Полные данные банковской карты на стороне платформы не хранятся.

3. Цели обработки

Создание аккаунта, персонализация обучения, проверка заданий, расчёт прогноза, связь с пользователем, безопасность сервиса, проведение платежей и выполнение требований законодательства.

4. Защита и срок хранения

Данные защищаются организационными и техническими мерами и хранятся не дольше, чем требуется для заявленных целей или по закону.

5. Обращения пользователя

Чтобы запросить доступ, исправление или удаление данных, напишите на support@stedy.ru.
