СТЭДИ — ЧИСТАЯ ВЁРСТКА HTML / CSS / JS

Быстрый запуск
1. Распакуйте архив.
2. Для полноценной работы модулей откройте папку через локальный сервер:
   python3 -m http.server 8000
3. Перейдите в браузере на http://localhost:8000

Главные файлы
- index.html — полная главная страница;
- login.html / register.html — авторизация и регистрация;
- onboarding.html — настройка цели и маршрута;
- diagnostic.html — диагностическая задача и результат;
- dashboard.html — компактный кабинет ученика;
- lesson.html — тренажёр из 19 реальных заданий варианта 89892516;
- exam.html — короткий пробник из 3 случайных заданий с новой подборкой при каждом старте;
- data/ege-89892516.json — вопросы, ответы, решения и локальные пути к изображениям;
- assets/tasks/89892516 — иллюстрации и формулы заданий, сайт не загружает их извне;
- scripts/import_sdamgia_variant.py — повторная выгрузка варианта из источника;
- map.html — интерактивная карта знаний;
- profile.html — профиль, баланс, подписка и уведомления;
- pricing.html — тарифы;
- privacy.html — страница политики с местами для реквизитов оператора;
- styles.css — базовые стили прежних внутренних экранов;
- steady.css — дизайн-система Стэди, главная и новый кабинет;
- config.js — единственная точка настройки адреса API;
- api.js — API-клиент без привязки к конкретному backend-фреймворку;
- app.js — интерфейс и подключение экранов к API;
- INTEGRATION.md — контракты и инструкция для backend-разработчика.

В проекте нет React, Vue, jQuery, npm, сборщика и внешних библиотек.

Задания
На экране lesson.html доступны задания 1–19. Для 1–12 ответ проверяется локально,
для 13–19 сохраняется развёрнутое решение и доступен эталонный разбор. Прогресс
хранится в localStorage браузера. Чтобы обновить исходные данные, запустите из
корня проекта:
   python3 scripts/import_sdamgia_variant.py

Сами задания и решения атрибутированы в JSON и интерфейсе: источник — РЕШУ ЕГЭ,

Подключение backend
Укажите адрес API в config.js:
window.STEADY_CONFIG = { apiBaseUrl: "https://api.example.ru" };

Пока адрес пустой, интерфейс работает в демонстрационном режиме. После указания
адреса формы, профиль, платежи, баланс, уведомления, миссии и ИИ-чат автоматически
переходят на реальные запросы. Подробности — в INTEGRATION.md.

Перед публикацией
- внесите юридические реквизиты в privacy.html;
- укажите production API URL в config.js;
- замените support@stedy.ru, если будет использоваться другой адрес поддержки;
- настройте CORS, cookie/domain и HTTPS на стороне backend.
