ATLAS AI — ЧИСТАЯ ВЁРСТКА HTML / CSS / JS

Как открыть:
1. Распакуйте архив.
2. Откройте файл index.html в браузере.

Для размещения на хостинге загрузите всё содержимое папки в корневой каталог сайта.

Структура:
- index.html — главная страница;
- login.html — авторизация;
- register.html — регистрация;
- onboarding.html — первичная настройка;
- diagnostic.html — диагностика и результат;
- dashboard.html — кабинет ученика;
- lesson.html — решение задачи и ИИ-подсказки;
- map.html — интерактивная карта знаний;
- pricing.html — тарифы;
- styles.css — все стили и адаптив;
- app.js — вся интерактивность.

В проекте нет React, Vue, jQuery, npm, сборщиков или внешних библиотек.
Формы, оплата, реальные аккаунты и запросы к ИИ сейчас работают как frontend-демонстрация и готовы к подключению backend/API.
